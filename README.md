# Мат-повтор

Сайт, который напоминает повторять лекции по кривой забывания и превращает повторение в игру.

## Как пользоваться
1. Вкладка **Лекции** → добавьте лекцию.
2. Вставьте карточки, по одной на строку: `вопрос ;; ответ`. Формулы пишутся в `$...$` (LaTeX).
3. На главной нажмите **Играть**: 10 карточек за раунд, 3 жизни, комбо, XP, уровни и серия дней.
4. Оценивайте себя честно: «Забыл» вернёт карточку через 10 минут, «Легко» отодвинет её сильнее всего.

## Как работает расписание
Упрощённый алгоритм SM-2 (как в Anki): повторения идут через 1 → 3 → ~7 → ~16 дней и дальше с растущим интервалом. Ошибка сбрасывает карточку.

## Хранение данных
Всё в `localStorage` браузера. Раз в какое-то время делайте копию в **Настройках** (JSON), чтобы не потерять прогресс и перенести его на другое устройство.

## Запуск
Откройте `index.html` в браузере. Для публикации включите GitHub Pages (Settings → Pages → ветка main).

## Ограничения
Уведомления приходят, только пока вкладка с сайтом открыта. Настоящие push-уведомления при закрытом сайте потребуют сервера (например, Supabase) — можно добавить следующим шагом.
