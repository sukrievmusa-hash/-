# Мат-повтор

Сайт, который напоминает повторять лекции по кривой забывания и превращает повторение в игру.

## Что уже внутри
185 карточек по лекциям 1–6, 9 и практике 2: матрицы, определители, обратная матрица, СЛАУ (Крамер, Гаусс, матричный метод), ранг и теорема Кронекера–Капелли, векторы, скалярное, векторное и смешанное произведения, прямая на плоскости, множества, последовательности, пределы. Каждый день открывается 15 новых карточек (меняется в настройках).

Чтобы добавить новые лекции во встроенный набор, допишите их в `tools/build_cards.py` и запустите `python3 tools/build_cards.py lectures.js`. Новые карточки появятся у пользователя, прогресс по старым сохранится.

## Зачем это
На лекции материал понятен, но без практики через неделю забывается, и не всегда ясно, какая тема проседает. Сайт решает это тремя вещами:
- **Быстрый раунд**: 5 карточек, около 3 минут. Начать проще, чем сесть «решать задачи».
- **Диагностика**: по 2 вопроса из каждой лекции, около 5 минут. Показывает слабые лекции, и блок «Ваша слабая сторона» на главной ведёт прямо в тренировку по ним.
- **Три режима для каждой лекции**: «не понял» — разбор с нуля на пальцах, с картинками и примерами по шагам; «понял наполовину» — короткий разбор; «понял» — сразу карточки. Тексты объяснений лежат в `lessons.js`.
- **Напоминания в Telegram**: бот пишет раз в день, сколько карточек пора повторить и какая тема слабая. Сервер лежит в папке `backend/` (как запустить — в `backend/README.md`).

## Как пользоваться
1. Вкладка **Лекции** → добавьте лекцию.
2. Вставьте карточки, по одной на строку: `вопрос ;; ответ`. Формулы пишутся в `$...$` (LaTeX).
3. На главной нажмите **Быстрый раунд** (5 карточек) или **Полный раунд** (10): 3 жизни, комбо, XP, уровни и серия дней.
4. Оценивайте себя честно: «Забыл» вернёт карточку через 10 минут, «Легко» отодвинет её сильнее всего.

## Уровень знаний и ошибки
Вкладка **Прогресс**: шкала знаний по каждой лекции и разделу (растёт, когда карточка отодвигается на всё большие сроки, 100% = помните месяц и дольше) и список тем, где вы ошибаетесь чаще всего. Кнопка «Тренировать слабые места» собирает раунд из самых трудных карточек.

## Как работает расписание
Упрощённый алгоритм SM-2 (как в Anki): повторения идут через 1 → 3 → ~7 → ~16 дней и дальше с растущим интервалом. Ошибка сбрасывает карточку.

## Хранение данных
Всё в `localStorage` браузера. Раз в какое-то время делайте копию в **Настройках** (JSON), чтобы не потерять прогресс и перенести его на другое устройство.

## Запуск
Откройте `index.html` в браузере. Для публикации включите GitHub Pages (Settings → Pages → ветка main).

## Настройки сайта
Файл `config.js`: адрес сайта, номер Kaspi для кнопки «Поддержать автора» и адрес сервера Telegram-бота (`api`). Пока `api` пустой, блок Telegram на сайте скрыт.

## Ограничения
Уведомления браузера приходят, только пока вкладка с сайтом открыта. При закрытом сайте напоминает Telegram-бот.
